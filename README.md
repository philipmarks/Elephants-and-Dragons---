## A Complete Developer Takeover

If you haven't been paying attention to the data, PostgreSQL has completely reshaped the tech landscape:

* **2017 Stack Overflow Developer Survey:** Postgres ranked 4th, trailing MySQL by 30 percentage points.
* **2023:** Overtook MySQL to claim the #1 spot.
* **2026 Stack Overflow Developer Survey:** Postgres surged to **57.9% usage** among developers—opening up a massive 22-point lead over MySQL (35.1%) and dwarfing Oracle (9.4%).

Alongside dominating usage, it continues to hold the "Most Loved" and "Most Wanted" titles year after year.

## The Opportunity for Wales : Y Cyfle i Gymru

This is why I’m working hard to get the attention of:
* **Llywodraeth Cymru / Welsh Government**
* **Cardiff University / Prifysgol Caerdydd**
* **Cardiff Council**
* **Powys County Council** *(Gobeithio! Arall Trio!)*

The savings the Welsh public sector could make by migrating to open-source PostgreSQL are enormous. **#ReduceDebt**
